# Governance Documentation

This directory contains repository-development policy rather than research or system design.

- [`VERSION_CONTROL.md`](VERSION_CONTROL.md) — authoritative release sequence, scope, branches, tags, and acceptance gates.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — human contribution workflow.
- [`CHANGELOG.md`](CHANGELOG.md) — chronological release notes.

Do not place research definitions such as `q_cov` or backend behavior here. Link to the relevant design document instead.
