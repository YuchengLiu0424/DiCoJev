# Agent Task v0 — Protocol and Deterministic Harness

Authoritative scope and acceptance gate: `docs/governance/VERSION_CONTROL.md#v0--protocol-and-deterministic-harness`

## Implementation sequence

### A. Package skeleton

- create package modules for `schemas`, `generator`, `harness`, `backends`, `controller`, and `telemetry`;
- expose package version consistently;
- configure Ruff/Pytest;
- keep all imports GPU-free.

### B. Pydantic schemas

Implement typed models for:

```text
ImageRef
MultimodalState
DecisionBudget
DecisionRequest
Candidate
DecisionSpec
CoverageScore
SelectionScore
CandidateQuality
DecisionBackendResult
ControllerDecision
DecisionResponse
TelemetryEvent
ExpansionContext
EscalationRequest
MetaAction
BackendCapabilities
```

Match the semantics in `docs/design/DECISION_SEMANTICS.md`.

### C. Protocols

Implement async typed protocols for:

```text
CandidateGenerator
DecisionBackend
RiskController
EscalationTarget
```

Provider-specific fields are forbidden in these protocols.

### D. Harness

Implement deterministic functions for:

- JSON object extraction;
- bounded repair interface;
- `DecisionSpec` validation;
- candidate normalization;
- exact/normalized duplicate handling;
- stable ID assignment;
- synthetic NOTA insertion;
- Jev-compatible coverage/selection compiler;
- normalized backend-result ingestion;
- per-round trace structure.

### E. Deterministic implementations

- `FakeCandidateGenerator` with scripted outputs;
- `MockDecisionBackend` with scripted coverage/selection/errors;
- threshold `RiskController` capable of all four meta-actions;
- mock escalation target.

### F. Tests

Cover at minimum:

- valid/invalid schema cases;
- empty candidates;
- duplicate candidates;
- stable labels;
- NOTA is synthetic and excluded from semantic set;
- exact Jev compiler snapshots;
- `q_cov` never derived implicitly from `q_sel`;
- calibrated fields remain null unless explicitly populated;
- ACT/EXPAND/ABSTAIN/ESCALATE;
- backend unavailable / malformed probabilities fail closed;
- no GPU/network/key dependency.

### G. Example

Add one offline runnable example from `DecisionRequest` through controller response using only fake/mock components.

## Do not implement in this task

Do not add a real DLM, Jev network calls, Djev calls, cross-encoder model, image-model transport, calibration training, or native structured diffusion read unless required only as a type/interface stub already declared by the scope.
