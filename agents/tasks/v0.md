# Agent Task v0 — Protocol, Deterministic Harness, and Typed Feedback Loop

Authoritative scope/acceptance gate: `docs/governance/VERSION_CONTROL.md` v0 section.

## A. Package skeleton

Create/complete modules for:

```text
schemas
generator
harness
backends
controller
feedback
telemetry
```

Keep imports CPU-only and configure Ruff/Pytest.

## B. Typed schemas

Implement at minimum:

```text
ImageRef
MultimodalState

DecisionRequest
Candidate
DecisionSpec
CoverageScore
SelectionScore
CandidateQuality
DecisionBackendResult
MetaAction
FeedbackCode
FeedbackSignal
FeedbackBundle
LoopContext
GenerationFeedback
ControllerDecision
DecisionResponse
TelemetryEvent
BackendCapabilities
EscalationRequest
```

Follow `DECISION_SEMANTICS.md` and `FEEDBACK_PROTOCOL.md` exactly.

## C. Protocols

Async typed protocols:

```text
CandidateGenerator
DecisionBackend
RiskController
FeedbackCompiler
EscalationTarget
```

Provider-specific fields are forbidden in project-level protocols.

## D. Deterministic harness

Implement:

- JSON object extraction;
- bounded repair interface;
- `DecisionSpec` validation;
- candidate normalization;
- duplicate handling;
- stable candidate registry/ID assignment;
- synthetic NOTA;
- Jev-compatible coverage/selection compiler;
- normalized backend-result ingestion;
- per-round trace structure.

## E. Feedback loop

Implement:

- strict feedback-code validation;
- deterministic feedback compiler templates;
- stable `LoopContext` construction;
- fake generator support for prior candidates + feedback;
- threshold controller that emits meta-action + feedback bundle;
- one offline EXPAND loop that adds new candidates and reevaluates.

Do not make the feedback compiler decide meta-actions.

## F. Deterministic implementations

- `FakeCandidateGenerator` with scripted initial/expansion outputs;
- `MockDecisionBackend` with scripted coverage/selection/NOTA/errors;
- threshold `RiskController` capable of all four meta-actions;
- deterministic `FeedbackCompiler`;
- mock escalation target.

## G. Tests

Cover at minimum:

- valid/invalid schemas;
- empty/duplicate candidates;
- stable IDs across expansion;
- NOTA synthetic/excluded from semantic set;
- exact Jev compiler snapshots;
- `q_cov` never implicitly derived from `q_sel`;
- calibrated fields null unless populated;
- every feedback code validates and compiles deterministically;
- incompatible feedback bundle fails validation;
- EXPAND loop consumes feedback and preserves prior candidates;
- ACT/EXPAND/ABSTAIN/ESCALATE;
- malformed probabilities/backend unavailable/feedback failure fail closed;
- no GPU/network/key dependency.

## H. Offline example

Add one runnable example:

```text
DecisionRequest
-> fake candidate generation
-> mock low coverage
-> MISSING_ACTION + EXPAND
-> compiled feedback / LoopContext
-> second candidate generation
-> mock adequate coverage
-> ACT
```

## Do not implement

No real DiffusionGemma server, Jev network call, Djev call, cross-encoder checkpoint, native image transport, calibration training, or native structured diffusion read in v0 beyond explicitly declared type/interface stubs.
