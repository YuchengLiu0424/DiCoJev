# Agent Task v1 — Real DLM Generation and Reference Backends

Authoritative scope/gate: `docs/governance/VERSION_CONTROL.md` v1.

## A. Real DiffusionGemma generator

- implement configurable client/runtime adapter for `google/diffusiongemma-26B-A4B-it`;
- keep GPU serving in a separable environment from CPU-only app tests;
- build prompts/messages for project-native `DecisionSpec`;
- consume `LoopContext` and compiled typed feedback during expansion;
- enforce candidate limits, timeout, cancellation, and telemetry;
- route all raw output through the existing bounded harness.

## B. Runtime reproducibility

Implement/document a fresh-machine sequence for GPU/runtime check, model cache/download, server start, health check, initial candidate smoke test, and feedback-guided expansion smoke test. Do not commit model weights.

## C. JevCloudBackend

- environment-only credentials;
- use existing Jev compiler;
- parse dedicated `noul` coverage and `choice` selection;
- normalize timeout/provider errors;
- fixture tests require no live key.

## D. DjevLocalBackend

- configurable endpoint/model;
- Jev-compatible request support;
- label-token validation hook;
- parse coverage/selection and preserve diagnostics;
- report read latency separately from generation;
- integration tests are explicitly hardware/service gated.

## E. CrossEncoderDecisionBackend

- score candidates for selection;
- implement a separately named set-level coverage baseline/head/heuristic;
- record exact coverage method;
- do not alias max candidate score to `q_cov` except as an explicitly weak baseline.

## F. Feedback integration

- real generator receives typed feedback through `LoopContext`;
- ensure `MISSING_ACTION`, `TOOL_MISMATCH`, and `REDUNDANT_SET` compilation can alter generation constraints;
- preserve old candidate IDs/provenance across real regeneration;
- record feedback payload size and generation latency.

## G. Tests/examples

- provider fixtures and malformed responses;
- capability flags and config-only backend swap;
- invalid generator JSON -> harness repair/fail path;
- feedback-guided real-generator smoke fixture where hardware is available;
- same persisted candidate set can be evaluated by all compatible backends.

## Do not implement

No full multimodal closed-loop benchmark, project-owned native diffusion read, learned calibration/feedback policy, or shared-runtime optimization yet.
