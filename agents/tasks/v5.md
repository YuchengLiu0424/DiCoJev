# Agent Task v5 — Unified Multimodal Agent Runtime and Research Release

Authoritative scope/gate: `docs/governance/VERSION_CONTROL.md` v5.

## A. Unified DLM runtime

Expose stable internal operations:

```text
generate(request, loop_context)
structured_read(state, spec, candidates)
```

Share process/weights by default when safe; deeper state reuse requires correctness equivalence tests and benchmarks.

## B. Reuse experiments

Measure separate services, shared process/weights, shared multimodal preprocessing, and any additional safe cache/context reuse for latency, memory, and decision equivalence.

## C. Stable service API

Implement project-owned `/v1/decide`-style endpoint accepting backend-neutral state/goal/tools/constraints/budget and returning candidates, coverage/selection evidence, typed feedback, controller meta-action, trace summary, and execution result when enabled.

## D. Environment/tool boundary

Execution remains explicit/permissioned. Record transitions so subsequent observation can re-enter the same feedback-controlled loop.

## E. Full benchmark

Run reference backends, candidate corruption, multimodal conditions, calibration, feedback baselines/ablations, adaptive compute, latency/memory, feedback bandwidth, and risk-latency-token Pareto evaluation.

## F. Reproducibility release

Freeze configs, capture environment/hardware metadata, validate clean local install, validate documentation ownership/links, and retain baseline adapters.

## Completion rule

The release is complete only when the v5 acceptance gate and core research evaluation are reproducible; endpoint availability alone is insufficient.
