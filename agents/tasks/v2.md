# Agent Task v2 — Multimodal Coverage-Aware Closed Loop

Authoritative scope and acceptance gate: `docs/governance/VERSION_CONTROL.md#v2--native-multimodal-coverage-aware-closed-loop`

## Implementation sequence

### A. Multimodal state transport

- support image file/path/bytes/data-URL references through typed `ImageRef`;
- pass images natively to supported generator/backend adapters;
- enforce request size/type checks;
- ensure telemetry excludes image bytes by default;
- raise explicit capability errors for unsupported native multimodal paths.

### B. Expansion controller

Implement budget-aware routing using:

```text
coverage threshold
selection threshold
NOTA evidence
max expansions
max total candidates
latency/compute budget
```

Keep controller reason codes deterministic and inspectable.

### C. Expansion flow

- build `ExpansionContext` from prior round;
- request missing/different candidates rather than paraphrases;
- merge old/new candidates;
- preserve stable IDs for retained actions;
- rerun backend decision;
- append per-round trace.

### D. Candidate quality

Add rule-based flags for:

```text
invalid format
unavailable tool
explicit constraint violation
duplicate/redundant group
```

Do not conflate these flags with `q_cov`.

### E. Escalation

Implement typed escalation target interface and deterministic test target. Keep slow planner/human integration optional.

### F. Controlled fixtures

Create fixtures for:

- adequate set;
- all acceptable actions deleted;
- best action deleted but fallback remains;
- distractor-heavy set;
- duplicate-heavy set;
- NOTA-needed set;
- expansion recovers an acceptable action;
- ambiguous multimodal state.

### G. Integration report

Persist per-round coverage/selection/controller outputs and latency for candidate-deletion experiments.

## Do not implement in this task

Do not replace Djev with native structured read yet; do not fit production calibration models; do not perform shared-runtime optimization.
