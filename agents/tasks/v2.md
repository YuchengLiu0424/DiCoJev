# Agent Task v2 — Native Multimodal Coverage-Aware Closed Loop

Authoritative scope/gate: `docs/governance/VERSION_CONTROL.md` v2.

## A. Multimodal state transport

- support image path/reference/bytes/data URL through typed `ImageRef`;
- pass images natively to capable generator/backend adapters;
- enforce type/size checks;
- never log raw image bytes by default;
- fail explicitly on unsupported native multimodal paths.

## B. Closed-loop controller

Use coverage, selection, NOTA, quality, expansion limits, total candidate budget, and latency/compute budget to produce deterministic/inspectable controller actions and feedback bundles.

## C. Typed feedback behavior

Support controlled generation behavior for:

```text
MISSING_ACTION
AMBIGUOUS_SELECTION
INSUFFICIENT_INFORMATION
TOOL_MISMATCH
CONSTRAINT_FAILURE
REDUNDANT_SET
```

Keep `ADEQUATE` as the positive state signal. Do not add free-form reasoning to the canonical feedback payload.

## D. Loop flow

- build `LoopContext` from prior round;
- compile feedback deterministically;
- request qualitatively distinct candidates;
- merge old/new candidates;
- preserve stable IDs/provenance;
- rerun backend;
- append full per-round trace.

## E. Candidate quality and escalation

Add rule-based quality flags for invalid format, unavailable tool, explicit constraint violation, and redundancy. Keep these separate from `q_cov`. Implement typed escalation target and deterministic test target.

## F. Controlled fixtures

Include adequate, all-gold-deleted, best-only-deleted, distractor-heavy, duplicate-heavy, tool-mismatch, constraint-failure, NOTA-needed, insufficient-information, expansion-recovery, and ambiguous multimodal conditions.

## G. Integration report

Persist per-round coverage/selection/quality/feedback/controller outputs plus feedback bytes/tokens and latency.

## Do not implement

Do not replace Djev with native structured read, fit production calibration models, or optimize a shared DLM runtime yet.
